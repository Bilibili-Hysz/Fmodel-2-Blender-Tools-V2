# UEPOSE 姿势资产：修正后的流程与面板

## 使用入口

`FModel → 资产库 → 姿势资产`。导入 UEPOSE 后不再立即烘焙或清零当前角色；源文件的全部字节保存在专用 Blender Text 数据块中，随场景保存。骨骼变换、未匹配曲线和未知扩展不会因为没有网格就丢失。

1. **导入 UEPOSE**：无需先选择骨架或网格。默认解释为 CUE4Parse 加法姿势；不确定导出器约定时选择“未知，仅保存源数据”。
2. **选择姿势**：用搜索筛选姿势名或来源；列表按来源排列，并显示来源标签。详情显示源骨骼数和曲线数。
3. **指定目标**：选择目标骨架；未指定时使用活动骨架。按 UEFormat 原版忽略大小写绑定同名骨骼，跳过未匹配骨骼；不比较骨架身份。
4. **检查匹配**：只检查，显示匹配数量及跳过原因。检查结果是上次操作记录，应用时仍会重新校验。
5. **应用到骨架**：根据参考姿势计算并替换骨架姿势，同时设置匹配的形态键曲线，不插入关键帧。原 Action、NLA 和约束保持原样，若它们会继续驱动对象，会报告提醒。
6. **可选烘焙**：展开“形态键烘焙”，选择选中的绑定网格或全部绑定网格。同一源姿势的骨骼和曲线合成为每个网格的一个形态键。再次烘焙更新来源关联的结果。

高级设置可以改变所选源文件的单位缩放及加法解释约定，不需要原文件仍在磁盘。修改后已有烘焙结果需要重新烘焙。

## 面板组织原则

```text
姿势资产
  导入 UEPOSE                  刷新
  加载源库                    保存源库
  搜索姿势或来源…
  [姿势名称                  来源文件]

  当前姿势：Smile
  12 个骨骼 · 3 条曲线
  目标骨架：CharacterRig
  检查匹配（仅显示绑定情况）
  [           应用到骨架           ]

  ▸ 形态键烘焙
  ▸ 高级设置

  上次操作结果
  已应用 12 个骨骼、2 个曲线绑定
  未应用曲线：MaterialParameter
```

面板绘制不读取二进制源文件；解析发生在导入、刷新、检查及执行操作时。匹配结果与执行结果都保留在面板中，避免只能读取瞬时状态栏消息。未指定目标或源语义尚未确认时，应用按钮禁用；无目标网格时烘焙按钮禁用。

后续 UI 建议：实际规模达到数百个姿势时，再增加可折叠来源分组、收藏及姿势预览图。预览应有明确的恢复操作，并与“应用”区分。当前实现未加入自动悬停预览，避免浏览列表就改变角色。

## 保存与恢复

- “保存源库”写出独立 `.blend`，包含源记录，可以在原 UEPOSE 文件缺失的情况下加载并重新应用/烘焙。文件写入先使用同目录临时文件，完成后替换目标。
- “加载源库”先验证所有源记录，按来源 ID 更新已有记录；重复加载不会重复列出同一源。损坏的输入不会覆盖当前记录。
- V10 使用 ObjectPath 作为来源标识；没有 ObjectPath 的旧格式使用源绝对路径。同一 ObjectPath 被视为同一源的新版本，跨游戏资源路径相同时应使用独立场景/姿势库。
- 原始字节采用 Base64 存入 JSON，会增加存储体积。当前单源上限为 32 MiB；保存的 `.blend` 启用压缩。
- 烘焙只更新本功能记录的源条目到形态键名称的对应关系；此前旧导入器生成的形态键不会自动覆盖。用户手动重命名/删除派生形态键后，重新烘焙可能创建新键。

## 当前语义与限制

- 使用 Vendor 解析器读取 V0–V10 布局；本次未改动 Vendor 代码或锁定摘要。
- 仅在明确选择 CUE4Parse 加法约定后求值，遵循现有 Vendor 的坐标转换、post quaternion 和 `1 + scale delta`。这不代表所有自定义 FModel fork 都采用相同约定。
- 骨骼应用支持无网格骨架及无权重辅助骨骼。应用的是完整参考姿势上的结果，源条目没有覆盖的骨骼返回对应参考状态，不是叠加到当前任意姿态。
- 应用曲线目前映射到同名形态键；其他用途的曲线保留在源记录中并报告未应用。
- 烘焙在临时骨架和临时网格上求值，保持原骨架姿势、Action、选择和模式。网格按 Armature modifier 绑定发现，不要求是骨架子对象。
- 烘焙使用目标骨架修改器和源姿势指定的形态键曲线，排除其他修改器和骨骼约束；需可编辑、单用户、相对形态键网格。多目标骨架修改器及绝对形态键不在当前支持范围。
- 新建结果没有形变时返回失败/跳过信息；原始曲线和姿势仍保留。已有来源关联的键即使更新为参考状态也会更新，防止旧形变残留。
- 本轮没有加入单帧 Action 导出、Pose Asset 标记、时序动画打包、可调混合权重或完整 Unreal 重定向。

## 验证

- 纯 Python 与现有合同测试：538 passed，52 subtests passed。
- Blender 5.2.1 独立进程：无网格 helper 姿势应用、双网格骨骼/曲线合成、重复更新、父子矩阵一致性、Pose Mode 与现有 Action 保留、缺身份拒绝、故障清理、零烘焙输出、原文件缺失后库重载、重复加载去重和损坏库拒绝。
- 使用合成标准 V10 样本进行行为验收；真实游戏角色的 reorient、约束、非单位缩放和最终表情视觉效果仍需实物 GUI 验收。未执行安装或修改用户当前 Blender 场景。

执行方法见 `scripts/blender_pose_asset_smoke.py` 和 `tests/README.md`。
